# mealie_export

Generates a simple HTML file from a [Mealie](https://github.com/mealie-recipes/mealie) export.

The recipes and photos are not mine. A link to the originals is included where known.

## Usage

```bash
python -m code.mealie_export --url https://mealie.example.com
# or
python -m code.mealie_export -u https://mealie.example.com
```
